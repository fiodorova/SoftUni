**4.	Reverse an Array of Strings**

Write a program, which receives an **array of strings**. Your task is to **reverse** and **print** its elements on a single line, space-separated.

**Note:** Reverse array elements **without** creating a new array.

**Hints** </br>
•	Loop to the **half-length** of the array </br>
•	Create a function to swap **two elements** inside an array
