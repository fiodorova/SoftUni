**5.	Sum Even Numbers**

Write a program, which receives an **array** of strings, **parse** them into numbers, and **sum** only the **even** numbers.

**Hints** </br>
•	Parse each string to number </br>
•	Create a variable for the sum </br>
•	Iterate through all elements in the array with a **for-of** loop </br>
•	Check if the number is **even** </br>
•	Print the total sum
