**6.	Even and Odd Subtraction**

Write a program that calculates the **difference** between the sum of the **even** and the sum of the **odd** numbers in an array.

**Hints** </br>
•	Parse each string to number </br>
•	Create two variables - for **even** and **odd** sum </br>
•	Iterate through all elements in the array with **for-of** loop and check if the number is odd or even </br>
•	Print the difference
