**7.	Equal Arrays**

Write a program, which receives two string arrays, and prints on the console whether they are **identical** or **NOT**. 

Arrays **are identical** if their elements are **equal**. If are identical, find the **sum** of the first array and print the following message: </br>
&emsp; **\`Arrays are identical. Sum: {sum}\`** </br>
 
If the arrays are **NOT identical**, find the **first index** where the arrays **differ** and print the following message: </br>
&emsp; **\`Arrays are not identical. Found difference at {index} index\`**
 
**Hints** </br>
&emsp; •	First, we receive **two** arrays of strings and parse them. </br>
&emsp; •	Iterate through the arrays and **compare all elements**. If the elements are **NOT equal**, print the required message and break the loop. </br>
&emsp; •	Think about how to solve the other part of the problem.
