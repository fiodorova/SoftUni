**8.	Condense Array to Number**
	
Write a program, which receives an array of numbers, and **condenses** them by **summing** adjacent couples of elements until a **single number** is obtained. 

**Hints** </br> 
While we have more than one element in the array **nums[]**, repeat the following: </br> 
&emsp; •	Allocate a new array **condensed[]** of size **nums.Length-1**. </br> 
&emsp; •	Sum the numbers from **nums[]** to **condensed[]**: </br> 
&emsp; &emsp; **o	condensed[i] = nums[i] + nums[i+1]** </br> 
&emsp; **•	nums[] = condensed[]** </br>
