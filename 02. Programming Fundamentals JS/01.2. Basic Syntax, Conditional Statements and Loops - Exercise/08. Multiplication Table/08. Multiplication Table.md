**8.	Multiplication Table**

You will receive a **number** as a parameter. Print the **10 times table** for this **number**. See the examples below for more information.

**Output** </br>
Print every row of the table in the following format: </br>
**{number} X {times} = {product}**

**Constraints** </br>
· The number will be an **integer** will be in the interval **[1…100]**

**Examples**
<pre>

5	      5 X 1 = 5      2	     2 X 1 = 2

          5 X 3 = 15             2 X 3 = 6
          5 X 4 = 20             2 X 4 = 8
          5 X 5 = 25             2 X 5 = 10
          5 X 6 = 30             2 X 6 = 12
          5 X 7 = 35             2 X 7 = 14
          5 X 8 = 40             2 X 8 = 16
          5 X 9 = 45             2 X 9 = 18
          5 X 10 = 50		     2 X 10 = 20
