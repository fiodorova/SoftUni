**1.	Ages**

Write a function that determines whether based on the given **age** a person is: **baby, child, teenager, adult, elder**.

The input comes as a **single number parameter**. The bounders are: </br>
**·	0-2 (age) – is a baby; </br>
·	3-13 (age) – is a child; </br> 
·	14-19 (age) – is a teenager; </br>
·	20-65 (age) – is an adult; </br>
·	>=66 (age) – is an elder;** </br> 
**·**	In all other cases print – **"out of bounds"**;

The **output** should be printed to the console.
