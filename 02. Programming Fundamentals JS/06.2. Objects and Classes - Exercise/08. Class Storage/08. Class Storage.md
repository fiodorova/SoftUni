**8.	\*Class Storage**

Create a **class Storage**. It should have the following **properties**, while the **constructor** should only receive a **capacity**: </br>
&emsp; •	**capacity** – a number that **decreases when adding a given quantity** of products to storage </br>
&emsp; •	**storage – list of products** (object). **Each product** should have: </br>
&emsp; &emsp; o	**name** - a string </br>
&emsp; &emsp; o	**price** – a number (price is for a single piece of product) </br>
&emsp; &emsp; o	**quantity** – a number </br>
&emsp; •	**totalCost** – the sum of the cost of the products

The class should also have the following **methods**: </br>
&emsp; •	**addProduct** – a function that receives a product and adds it to the storage </br>
&emsp; •	**getProcuts** – a function that returns all the products in storage in **JSON** format, each on a new line
