**5.	Tseam Account**

As a gamer, Peter has Tseam Account. He loves to buy new games. You are given Peter's account with all of his games-> **strings, separated** by space. Until you receive **"Play!"** you will be receiving commands which Peter does with his account.

You may receive the following commands: </br>
&emsp; •	**Install {game} - add** the game at the **last** position in the account, but only if it **isn't** installed already. </br>
&emsp; •	**Uninstall {game} - delete** the game if it **exists**. </br>
&emsp; •	**Update {game} - update** the game **if it exists** and place it in the **last position**. </br>
&emsp; •	**Expansion {game}-{expansion}** - check if the game exists and **insert** after it the expansion in the following format: **"{game}:{expansion}"**;

**Input** </br>
&emsp; •	On the **first input line** you will receive Peter`s **account** - a **sequence** of game names, **separated** by space. </br>
&emsp; •	Until you receive **"Play!"** you will be receiving **commands**. 

**Output** </br>
&emsp; •	As output, you must print Peter`s Tseam **account**. 

**Constraints** </br>
&emsp; •	The **command will always be valid.** </br>
&emsp; •	The **game** and **expansion** will be strings and will contain any character, except **'-'**. </br>
&emsp; •	Allowed working **time / memory: 100ms / 16MB.**
