**6. Password Validator**

Write a function that checks if a given password is valid. Password validations are: </br>
&emsp; •	The **length** should be **6 - 10** characters (inclusive) </br>
&emsp; •	It should consist **only of letters** and **digits** </br>
&emsp; •	It should have **at least** 2 digits 

If a password is a valid print: **"Password is valid"**.

If it is **NOT** valid, for every unfulfilled rule print a message: </br>
&emsp; **•	"Password must be between 6 and 10 characters" </br>
&emsp; •	"Password must consist only of letters and digits" </br>
&emsp; •	"Password must have at least 2 digits"**
