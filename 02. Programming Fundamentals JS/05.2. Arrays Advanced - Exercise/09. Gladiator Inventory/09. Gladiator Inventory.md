**9. \*Gladiator Inventory**
0
As a gladiator, Peter has a cool **Inventory**. He loves to buy new equipment. You are given Peter’s inventory with all of his equipment -> **strings**, separated by whitespace. 

You may receive the following **commands**: </br>
&emsp; **•	Buy {equipment} </br>
&emsp; •	Trash {equipment} </br>
&emsp; •	Repair {equipment} </br>
&emsp; •	Upgrade {equipment}-{upgrade}**

If you receive the **Buy command**, you should **add** the equipment at the last position in the inventory, but only if it isn't bought already. </br>
If you receive the **Trash command, delete** the equipment if it exists. </br>
If you receive the **Repair command**, you should **repair** the equipment if it exists and place it in the **last position**. </br>
If you receive the **Upgrade command**, you should check if the equipment exists and **insert** after it the upgrade in the following format: **"{equipment}:{upgrade}"**.

**Input / Consrtaints** </br>
You will receive an **array of strings**. Each element of the array is a command. </br>
&emsp; •	In the **first input element**, you will receive Peter's **inventory** – a sequence of equipment names, separated by space.

**Output** </br>
As **output**, you must print Peter's **inventory** on one line, **separated** by a space. 

**Constraints** </br>
&emsp; •	The **command will always be valid**. </br>
&emsp; •	The **equipment** and **Upgrade** will be strings and will contain any character, except '-'. </br>
&emsp; •	Allowed working **time / memory: 100ms / 16MB**.
