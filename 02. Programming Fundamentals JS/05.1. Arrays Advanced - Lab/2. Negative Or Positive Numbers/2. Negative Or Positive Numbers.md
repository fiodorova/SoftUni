**2.	Negative or Positive Numbers**

Write a function that processes the elements in an **array** one by one and produces a **new** array. **Prepend** each **negative** element at the front of the array (**as** the **first element**) and **append** each **positive** (or**0**) element at the end of the array.

The **input** comes as an array of string elements holding numbers.

The **output** is printed on the console, each element on a new line.

**Hints** </br>
&emsp; •	Write a function that receives an array as an argument. </br>
&emsp; •	Declare variable named **result** that will keep the array. </br>
&emsp; •	You can use **for** loop to go around the items one by one. </br>
&emsp; •	If the current element is a **negative number**, you can use the **unshift()** method to add the number at the **beginning** of the array. </br>
&emsp; •	Otherwise, if the current element is a **positive** number (**or 0**), use a **push()** method to add the number to the **end** of the array. </br>
&emsp; •	Print on the console, each element of the array on a new line.
