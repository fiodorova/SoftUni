**8.	Array Manipulations**

Write a function that manipulates an **array of numbers**. </br>
&emsp; •	**Add {number}:** add a number to the **end** of the array </br>
&emsp; •	**Remove {number}:** remove **all occurrences** of a particular **number** from the array </br>
&emsp; •	**RemoveAt {index}:** removes number at a **given index** </br>
&emsp; •	**Insert {number} {index}:** inserts a number at a **given index** </br>

**Note: All the indices will be valid!**

The **input** comes as an **array of strings**. The first element will be a string containing the **array to manipulate**. Every other **command** you receive will also be a string.

The **output** is the manipulated array printed on the console on a single line, **separated by space**.
