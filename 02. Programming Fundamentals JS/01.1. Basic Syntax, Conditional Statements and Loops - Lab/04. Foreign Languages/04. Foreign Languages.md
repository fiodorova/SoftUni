**4.	Foreign Languages**

Write a program, which prints the language, that a given country speaks. You can receive only the following combinations: </br>
&emsp; •	English **is spoken** in England and USA; </br>
&emsp; •	Spanish **is spoken** in Spain, Argentina, and Mexico; </br>
&emsp; •	For the others, we should print **"unknown"**;

**Input** </br>
You will receive a **single country name.**

**Output** </br>
**Print** the **language**, which the country **speaks**, or if it is **unknown** for your program, print **"unknown"**.
