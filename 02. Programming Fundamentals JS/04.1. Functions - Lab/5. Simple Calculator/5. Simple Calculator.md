**5. Simple Calculator**

Write a function that receives **three parameters** and write an **arrow function** that calculates the result depending on the operator. Operator can be **'multiply', 'divide', 'add', 'subtract'**. 

**Input** </br>
The input comes as parameters named **numOne, numTwo, operator**.

**Hints** </br>
&emsp; •	Use **switch** statements for the different operators.
