**3.	Merge Arrays**

Write a function, which receives **two string arrays** and **merges** them into a **third** array. </br> 
&emsp; •	If the **index** of the element is **even**, add into the third array the **sum** of **both elements** at that index </br>
&emsp; •	If the **index** of the element is **odd**, add the **concatenation** of both elements at that index

**Input** </br>
As **input**, you will receive **two string arrays** (with equal length).

**Output** </br>
As **output**, you should print the resulting **third array**, each element separated by " - ".
