**5.	Amazing Numbers**

Write a **function**, which as **input** will receive a **number**. </br>
**Check** and print if it is **amazing** or **not** into the following format: </br>
	**"{number} Amazing? {True or False}"**
  
An amazing number includes the **digit 9** the sum of its digits. </br>
**Examples** for amazing numbers are 1233 (1 + 2 + 3 + 3 = 9), 583472 (5 + 8 + 3 + 4 + 7 + 2 = 29)
