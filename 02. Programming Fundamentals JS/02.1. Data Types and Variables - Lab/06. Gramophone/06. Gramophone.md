**6.	Gramophone**

Write a **function**, which as **input** will receive **3 parameters (strings)** </br>
&emsp; **•	The first string** is the name of the **band** </br>
&emsp; **•	The second string** is the name of the **album** </br>
&emsp; **•	The third** is holding a **song** name from the album

You have to find out how many **times** the plate will **rotate** the given song from the album. </br>
The plate makes a full rotation every **2.5** seconds. </br>
The song **duration in seconds** is calculate by the given formula: </br>
 &emsp; 	**(albumName.length * bandName.length) * song-name.length / 2**

As **output**, you should print the following message: </br>
 &emsp;      **\`The plate was rotated {rotations} times.\`**

Rotations should be **rounded up**.
