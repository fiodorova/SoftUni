**3.	Largest Number**

Write a function that takes **three number arguments** as input and finds the **largest** of them. Print the following text on the console:  **`The largest number is {number}.`**.

The **input** comes as **three number arguments** passed to your function.

The **output** should be printed to the console.

**Hints** </br>
&emsp; •	Write a function that receives three number arguments. </br>
&emsp; •	Declare a variable named **result** that will keep the result. </br>
&emsp; •	Make several checks to find out the largest of the three numbers. Start with num1. </br>
&emsp; •	Do the same for the others. </br>
&emsp; •	Print the result on the console.
