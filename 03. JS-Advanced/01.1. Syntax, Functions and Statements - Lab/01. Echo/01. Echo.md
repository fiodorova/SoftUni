**1.	Echo Function**

Write a JS function that takes **one string parameter** and **prints** on two lines the **length** of the parameter and then the **unchanged parameter** itself.

**Hints**
&emsp; •	Write a function that receives a single **parameter**.
&emsp; •	Use the console.log function to print text on the console. Each call prints a newline automatically.
&emsp; •	The string’s **length property** is used to determine how many characters are in a given string
