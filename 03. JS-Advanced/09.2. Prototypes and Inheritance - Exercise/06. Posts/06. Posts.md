**6. Posts**

You need to create several classes for **Posts**.

Implement the following classes: </br>
&emsp; •	**Post**, which is initialized with the **title** (String) and **content** (String) </br>
&emsp; &emsp; o	The **2** arguments should be **public members** </br>
&emsp; &emsp; o	The **Post** class should also have **toString()** function which returns the following result: </br>
&emsp; &emsp; **"Post: {postTitle}" </br>
&emsp; &emsp; "Content: {postContent}"** </br>

&emsp; •	**SocialMediaPost**, which inherits the **Post** class and should be initialized with **2 additional arguments - likes** (Number) and **dislikes** (Number). The class should hold: </br>
&emsp; &emsp; o	**comments**(Strings) -  an array of strings </br>
&emsp; &emsp; o	**addComment**(comment)- a function, which **adds** comments to that array </br>
&emsp; &emsp; o	The class should extend the **toString**() function of the **Post** class, and should return the following result: </br>
&emsp; &emsp; **"Post: {postTitle}" </br>
&emsp; &emsp; "Content: {postContent}" </br>
&emsp; &emsp; "Rating: {postLikes - postDislikes}" </br>
&emsp; &emsp; "Comments:" </br>
&emsp; &emsp; " * {comment1}" </br>
&emsp; &emsp; " * {comment2}" </br>
&emsp; &emsp; . . .**

In case **there are no comments**, return information only about the **title, content**, and **rating** of the **post**.

&emsp; •	**BlogPost**, which inherits the **Post** class: </br>
&emsp; &emsp; o	The **BlogPost** class should be initialized with **1 additional argument - views**(Number). </br>
&emsp; &emsp; o	The **BlogPost** class should hold  </br>
&emsp; &emsp; - **view()** - which **increments** the **views** of the object with **1**, every time it is called. The function should **return the object** so that **chaining is supported**. </br>
&emsp; &emsp; o	The **BlogPost** class should extend the **toString()** function of the **Post** class, and should return the following result: </br>
&emsp; &emsp; **"Post: {postTitle}" </br>
&emsp; &emsp; "Content: {postContent}" </br>
&emsp; &emsp; "Views: {postViews}"**
