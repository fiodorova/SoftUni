**7. Computer \***

You need to implement the class hierarchy for a computer business, here are the classes you should create and support: </br>
&emsp; •	**Keyboard**  class that contains: </br>
&emsp; &emsp; o	**manufacturer** - string property for the name of the manufacturer </br>
&emsp; &emsp; o	**responseTime** - number property for the response time of the Keyboard </br>
&emsp; •	**Monitor** class that contains: </br>
&emsp; &emsp; o	**manufacturer** - string property for the name of the manufacturer </br>
&emsp; &emsp; o	**width** - number property for the width of the screen </br>
&emsp; &emsp; o	**height** - number property for the height of the screen </br>
&emsp; •	**Battery** class that contains: </br>
&emsp; &emsp; o	**manufacturer** - string property for the name of the manufacturer </br>
&emsp; &emsp; o	**expectedLife** - number property for the expected years of the life of the battery </br>
&emsp; •	**Computer** – an **abstract** class that contains: </br>
&emsp; &emsp; o	**manufacturer** - string property for the name of the manufacturer </br>
&emsp; &emsp; o	**processorSpeed** - a number property containing the speed of the processor in GHz </br>
&emsp; &emsp; o	**ram** - a number property containing the RAM of the computer in Gigabytes </br>
&emsp; &emsp; o	**hardDiskSpace** - a number property containing the hard disk space in Terabytes </br>
&emsp; •	**Laptop** - class **extending** the **Computer** class that contains: </br>
&emsp; &emsp; o	**weight** - a number property containing the weight of the Laptop in Kilograms </br>
&emsp; &emsp; o	**color** - a string property containing the color of the Laptop </br>
&emsp; &emsp; o	**battery** - an instance of the **Battery** class containing the laptop's battery. There should be a **getter** and a **setter** for the property and validation that the passed-in argument is an instance of the Battery class. </br>
&emsp; •	**Desktop** - concrete class **extending** the **Computer** class that contains: </br>
&emsp; &emsp; o	**keyboard** - an instance of the **Keyboard** class containing the Desktop PC's Keyboard. There should be a **getter** and a **setter** for the property and validation that the passed-in argument is an instance of the Keyboard class. </br>
&emsp; &emsp; o	**monitor** - an instance of the **Monitor** class containing the Desktop PC's Monitor. There should be a **getter** and a **setter** for the property and validation that the passed-in argument is an instance of the **Monitor** class. </br>

Attempting to instantiate an abstract class should throw an **Error**, attempting to pass an object that is not of the expected instance (ex. an object that is not an instance of Battery to the laptop as a battery) should throw a **TypeError**.
