**1.	Array Extension**

Extend the built-in **Array** object with additional functionality. Implement the following functionality: </br> 
&emsp; •	**last()** - returns the last element of the array </br> 
&emsp; •	**skip(n)** - returns a new array which includes all original elements, except the first **n** elements; **n** is a **Number** parameter </br> 
&emsp; •	**take(n)** - returns a new array containing the first n elements from the original array; **n** is a **Number** parameter </br> 
&emsp; •	**sum()** - returns a sum of all array elements </br> 
&emsp; •	**average()** - returns the average of all array elements

**Input / Output** </br> 
Input for functions that expect it will be passed as valid parameters. Output from functions should be their **return** value.

**Constraints** </br> 
Structure your code as an **IIFE**.
