**2.	Data Class**

Write a **class Request** that holds data about an HTTP request. It has the following properties: </br>
**•	method** (String) </br>
**•	uri** (String) </br>
**•	version** (String) </br>
**•	message** (String) </br>
**•	response** (String) </br>
**•	fulfilled** (Boolean) 

The first four properties (**method, uri, version, message**) are set through the **constructor**, in the listed order. The **response** property is initialized to **undefined** and the **fulfilled** property is initially set to **false**.

**Constraints** </br>
•	The constructor of your class will receive **valid parameters**. </br>
•	Submit the class definition as is, **without** wrapping it in any function.
