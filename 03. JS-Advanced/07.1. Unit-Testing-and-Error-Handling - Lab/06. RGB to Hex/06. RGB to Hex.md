**6.	RGB to Hex**

Write tests to check the functionality of the following code:

&emsp; &emsp; **rgb-to-hex.js** </br>

function rgbToHexColor(red, green, blue) { </br>
&emsp;     if (!Number.isInteger(red) || (red < 0) || (red > 255)){ </br>
&emsp; &emsp;         return undefined; // Red value is invalid </br>
&emsp;     } </br>
&emsp;     if (!Number.isInteger(green) || (green < 0) || (green > 255)){ </br>
&emsp; &emsp;         return undefined; // Green value is invalid </br>
&emsp;     } </br>
&emsp;     if (!Number.isInteger(blue) || (blue < 0) || (blue > 255)){ </br>
&emsp; &emsp;         return undefined; // Blue value is invalid </br>
&emsp;     } </br>
&emsp;     return "#" + </br>
&emsp; &emsp;         ("0" + red.toString(16).toUpperCase()).slice(-2) + </br>
&emsp; &emsp;         ("0" + green.toString(16).toUpperCase()).slice(-2) + </br>
&emsp; &emsp;         ("0" + blue.toString(16).toUpperCase()).slice(-2); </br>
}

Your tests will be supplied with a function named **'rgbToHexColor()'**, which takes **three arguments**. It should meet the following requirements: </br>
&emsp; •	Take three **integer numbers**, representing the red, green, and blue values of RGB color, each **within the range [0…255]** </br>
&emsp; •	**Return** the same color in hexadecimal format as a **string** (e.g. **'#FF9EAA'**) </br>
&emsp; •	**Return undefined** if **any** of the input parameters are of an **invalid type** or **not** in the **expected range**
