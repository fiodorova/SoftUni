**5.	Check for Symmetry**

Write tests to check the functionality of the following code:

&emsp; &emsp; **checkForSymmetry.js** </br>
function isSymmetric(arr) { </br>
&emsp;     if (!Array.isArray(arr)){ </br>
&emsp; &emsp;         return false; // Non-arrays are non-symmetric </br>
&emsp;     } </br>
&emsp;     let reversed = arr.slice(0).reverse(); // Clone and reverse </br>
&emsp;     let equal = (JSON.stringify(arr) == JSON.stringify(reversed)); </br>
&emsp;     return equal; </br>
}

Your tests will be supplied with a function named **'isSymmetric()'**. It should meet the following requirements: </br>
&emsp; •	Take an **array** as an argument </br>
&emsp; •	**Return false** for any input that isn’t of the **correct type** </br>
&emsp; •	**Return true** if the input array is **symmetric** </br>
&emsp; •	Otherwise, **return false**
