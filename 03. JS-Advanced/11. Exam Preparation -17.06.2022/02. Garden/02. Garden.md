Write a class **Garden**, which implements the following functionality:

**Functionality**

**Constructor** </br>
Should have these **3** properties: </br>
•	**spaceAvailable** – Number </br>
•	**plants** – Array (empty) </br>
•	**storage** – Array (empty) </br>
**At the initialization of the Garden class**, the **constructor** accepts the **spaceAvailable**.

**addPlant (plantName, spaceRequired)**

The **plantName** is of type **string**, while the **spaceRequired** is of type **number**. </br>
•	If there is **not enough space in the garden** for the new plant, **throw an Error:**

**"Not enough space in the garden."**

•	Otherwise, this function should add the plant with the properties: **plantName, spaceRequired, ripe: default false, quantity: default 0** to the plants array, reduce the space available with the space required by the plant, and **return**: </br>
**"The {plantName} has been successfully planted in the garden."**

**NOTE: Plant names will be unique.**

**ripenPlant(plantName, quantity)**

The **quantity** is of type **number**. </br>
•	If the plant is not found, **throw an Error**: </br>
**"There is no {plantName} in the garden."** </br>
•	If the plant is already ripe, **throw an Error**: </br>
**"The {plantName} is already ripe."** </br>
•	If the received quantity is less than or equal to 0, **throw an Error**: </br>
**"The quantity cannot be zero or negative."** </br>
•	Otherwise, this function should set the ripe property of the particular plant to true and add the quantity to the quantity property of the plant. If the quantity passed as a parameter is 1, **return**: </br>
**"{quantity} {plantName} has successfully ripened."**

If the quantity parameter is greater than 1, **return**: </br>
**"{quantity} {plantName}s have successfully ripened."**

**harvestPlant(plantName)**  </br>
•	If the plant is **not found**, throw **an Error**: </br>
**"There is no {plantName} in the garden."** </br>
•	If the plant **is not ripe**, throw **an Error**: </br>
**"The {plantName} cannot be harvested before it is ripe."** </br>
•	Otherwise, this function should **remove** the plant from the plants array, add it to storage with properties **plantName** and **quantity**, free up the total space that the plant required, and **return**: </br>
**"The {plantName} has been successfully harvested."**

**generateReport()** </br>
This method should **return** the complete information about the garden: </br>
•	On the first line: </br>
**"The garden has { spaceAvailable } free space left."** </br>
•	On the second line list all plants that are in the garden **ordered alphabetically by plant name ascending** in the format: </br>
**"Plants in the garden: {plant1Name}, {plant2Name}, {…}"** </br>
•	On the third line add: </br>
	If there are no plants in the storage, print: </br>
**"Plants in storage: The storage is empty."** </br>
If there are plants in the storage list them in the format: </br>
**"Plants in storage: {plant1Name} ({plant1Quantity}), {plant2Name}, ({plant2Quantity}), {…}"**
