**2.	Delete from Table**

Write a program that **takes** an **email** from an **input field** and **deletes** the matching row from a table. </br>
&emsp; •	If entry is found, the **textContent** in the element with **id="result"** must be set to **"Deleted."** </br>
&emsp; •	Otherwise, an **error** should be displayed in a **\<div\>** with **id="result"**. The error should be **"Not found."** 

Submit **only** the **deleteByEmail()** function in Judge. 

**Input/Output** </br>
There will be no input/output, your program should instead **modify** the DOM of the given HTML document.
