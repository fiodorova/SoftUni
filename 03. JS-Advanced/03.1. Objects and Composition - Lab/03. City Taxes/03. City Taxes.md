**3.	City Taxes**

This task is an extension of Problem 1, you may use your solution from that task as a base.

You will receive a city’s **name** (string), **population** (number), and **treasury** (number) as arguments, which you will need to set as **properties** of an **object** and **return** it. In addition to the input parameters, the object must have a property **taxRate** with an initial value of **10**, and three **methods** for managing the city: </br>
&emsp; **•	collectTaxes()** - Increase **treasury** by  **population * taxRate** </br>
&emsp; **•	applyGrowth(percentage)** - Increase population by **given percentage** </br>
&emsp; **•	applyRecession(percentage)** - Decrease treasury by **given percentage** </br>

Round down the values after each calculation.

**Input** </br>
Your solution will receive three **valid** parameters. The methods that expect parameters will be tested with valid input.

**Output** </br>
Return an **object** as described above. The methods of the object modify the object and don’t return anything.
