**1.	Sort Array**

Write a function that **sorts an array** with **numeric** values in **ascending** or **descending** order, depending on an **argument** that is passed to it. 

You will receive a **numeric array** and a **string** as arguments to the function in your code. </br>
&emsp; •	If the second argument is **asc**, the array should be sorted in **ascending order** (smallest values first). </br>
&emsp; •	If it is **desc**, the array should be sorted in **descending order** (largest first).

**Input** </br>
You will receive a **numeric array** and a **string** as input parameters. 

**Output** </br>
The output should be the **sorted array**.
