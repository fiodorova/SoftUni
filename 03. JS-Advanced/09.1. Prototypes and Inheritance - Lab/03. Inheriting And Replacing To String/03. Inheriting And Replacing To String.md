**3.	Inheriting and Replacing toString**

Extend the **Person** and **Teacher** from the previous task and add a class **Student** inheriting from **Person** with additional property **course**. Add **toString()** functions to all classes, the formats should be as follows: </br>
&emsp; •	**Person** - returns **"Person (name: {name}, email: {email})"** </br>
&emsp; •	**Student** - returns **"Student (name: {name}, email: {email}, course: {course})"** </br>
&emsp; •	**Teacher** - returns **"Teacher (name: {name}, email: {email}, subject: {subject})"**

Try to reuse code by using the **toString()** function of the base class.
 
**Input / Output** </br>
There will be **NO** input. Your function should return an object containing the classes **Person, Teacher**, and **Student**.
