**1.	Person**

Write a JS program which takes **first** & **last** names as **parameters** and returns an object with **firstName, lastName** and **fullName ( "{firstName} {lastName}" )** properties which should be all **accessible**, we discovered that "accessible" also means "mutable". This means that: </br>
&emsp; •	If **firstName** or **lastName** have changed, then **fullName** should also be changed. </br>
&emsp; •	If **fullName** is changed, then **firstName** and **lastName** should also be changed. </br>
&emsp; •	If **fullName** is **invalid**, you should not change the other properties. </br>
&emsp; •	 A **valid full name** is in the format: **"{firstName} {lastName}"**.
