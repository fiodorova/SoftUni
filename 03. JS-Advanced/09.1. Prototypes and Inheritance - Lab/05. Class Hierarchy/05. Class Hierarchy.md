**5.	Class Hierarchy**

Write a function that returns **3** classes - **Figure, Circle**, and **Rectangle**. 

**Figure:** </br>
&emsp; •	Should have property units (**"m", "cm", "mm"**) with default value **"cm"** </br>
&emsp; •	Should have a **getter area** </br>
&emsp; •	Has method **changeUnits** that sets different units for that figure </br>
&emsp; •	**Has method toString**, which returns: </br>
&emsp; **`Figures units: {units}`**

**Circle:** </br>
&emsp; •	Extends **Figure** </br>
&emsp; •	Has a property **radius** </br>
&emsp; •	Overrides **area** getter to return the area of the Circle (PI * r * r) </br>
&emsp; •	**toString()** - should return a string representation of the figure in the format: </br>
&emsp; **`Figures units: {type} Area: {area} - radius: {radius}`**

**Rectangle:** </br>
&emsp; •	Extends **Figure** </br>
&emsp; •	Has properties **width, height**, and **units** (extended from the class Figure) </br>
&emsp; •	Overrides **area** getter to return the area of the **Rectangle** (width * height) </br>
&emsp; •	**toString()** - should return a string representation of the figure in the format: </br>
&emsp; **`Figures units: {type} Area: {area} - width: {width}, height: {height}`**

**Note:  All Parameters Passed in the Constructors Are in Centimeters ("cm")**

**Input / Output** </br>
There will be **no** input. Your function should return an object containing the **Figure, Circle**, and **Rectangle** classes.
